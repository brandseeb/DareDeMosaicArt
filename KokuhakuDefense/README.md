# 告白お断りします！〜2年B組防衛戦〜

iPhone縦持ち専用タワーディフェンスの初期プロトタイプです。ゲーム性の核を確認するため、現段階ではキャラクター画像を使わず、SpriteKitの図形と絵文字で表現しています。

## 実装済み

- 教卓のある前方エリア、8×10の配置エリア、マドンナエリアに分かれた教室
- 配置エリア外の上部左右2か所にある敵入口
- 配置エリア外の教室下部にあるマドンナとストレス値
- タップによる机の設置・撤去
- 両入口の経路を保証する完全封鎖防止
- 最短経路のプレビュー
- 左右から交互に出現する35人の告白者
- 3人のクラスメイトによる射程・威力・連射速度の異なる自動攻撃
- 敵HP、撃退数、ストレス、勝利・敗北
- 机を残したままのリトライと全消去リセット

## 起動方法

1. `KokuhakuDefense.xcodeproj` をXcodeで開く
2. Teamが自分のApple Developer Teamになっていることを確認
3. 接続したiPhoneを実行先に選択
4. Runする

対応OSはiOS 17以降、端末はiPhoneのみ、画面方向は縦向きのみです。

## 遊び方

1. 教室の空きマスをタップして机を配置する
2. 黄色い点で左右入口からの経路を確認する
3. `防衛開始！`を押す
4. クラスメイトが自動でラブレターを持った生徒を迎撃する
5. 35人を退け、マドンナのストレスが100%になる前に放課後を迎える

入口、マドンナ、クラスメイトのいるマスには机を配置できません。通路を完全に塞ぐ机も自動的にキャンセルされます。
